About SecretPix Security

How cryptography and steganography work together to safeguard your communication.

1. Authenticated Cryptography (AES-256-GCM)

SecretPix utilizes the native browser Web Crypto API to perform AES-256-GCM authenticated encryption. A unique 16-byte random salt and 12-byte initialization vector (IV) are generated via crypto.getRandomValues() for every single message. Keys are derived using PBKDF2 with 600,000 iterations of SHA-256, protecting against brute-force attacks.

2. Least Significant Bit (LSB) Steganography

Image steganography is the art of concealing confidential data inside pixel bytes. In 24-bit RGB images, each pixel consists of 8 bits for Red, Green, and Blue. SecretPix replaces only the Least Significant Bit (LSB) of each color channel. Changing the last bit modifies the color value by at most 1/256th—a difference invisible to the human eye.

3. Crucial Guidelines for Sharing

Always share encoded images as uncompressed files or documents!

Platforms like WhatsApp, Facebook, Instagram, or Discord re-compress uploaded images into lossy JPEGs. Lossy compression alters pixel values and will permanently destroy the embedded LSB data. Always send the encoded PNG as a document/raw file, via AirDrop, email attachment, or secure cloud drives.
